Immich accounts

Add one API key per person or server. Photos from every account are mixed together. People and albums with the same name are merged, so "Dave" plays every Dave from every account.

Where do I get a key? In Immich: avatar → Account settings → API keys → New API key. Give it asset.read, asset.view, asset.download, album.read, person.read and asset.update (for likes), or simply "all".
